## native
and for the first R experience away from the terminal or R GUI which will automatically lead to scripts that you can edit/save and run line-wise instead of hassling with an R history file, try:

- menu: create file \> R
- insert command like

```r
3+4*2
```

or any from the book, and then, an important missing:

- simply press CMD-enter (mac) or CTR-enter (windows) with the cursor being somewhere in or at the end of the line in the editor (or anywhere within a function) and you get your first computation or anything you commanded in that line. sure on an error you get an error :) but theres no line termination necessary or correct indendation of lines like in python. that can mean less errors but also may lead to scribbling instead coding.

- you can simply **comment out** a line with the raute like

```r
# commented out (runs not)
print("this command runs...")
```

- that way can create a complex script and run it completely (code \> run \> from the beginning) with simply commenting out not wanted commands within.
